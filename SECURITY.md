# Security policy

The latest public developer preview is the supported scope for security reports. It is a source preview of local review/export and GPU target selection; it does not include the full Studio application or model training runtime.

Please use GitHub's **Report a vulnerability** form for this repository to send a private report. Include the affected commit or release, clear reproduction steps, and a synthetic example where possible. Do not post exploitable details in a public issue or include credentials, private datasets, browser profiles, or personal records.

This policy does not offer a bug bounty or guarantee a response time or fix deadline.
